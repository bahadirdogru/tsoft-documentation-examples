    #T-Soft Dokümantasyonu

    T-Soft e-ticaret altyapısıyla entegrasyon ve tema yazan geliştiriciler ve onlara yardım eden yapay zekâ asistanları için tek bir başvuru noktası. Resmî sayfalarda, panel kodunda ve konsolda dağınık duran bilgiyi gerçek mağazada denenmiş çağrılarla bir araya getirir.

    Hangi yüzey?REST1, Admin API, Storefront ve tema arasında seçim, ilk çağrılar, terimler. REST1 web servisi38 modül, 428 metot. Form gövdesi, token, PascalCase alanlar, hata kodları. Admin API v3Panelin kendi kullandığı 357 uç: kurallar, yetkiler, ödeme bildirimi örneği. Uygulama platformuOAuth, 48 kapsam, 15 webhook olayı, panele gömülü uygulama, REST1’den geçiş. Storefront APIMobil uygulama ve headless vitrin için JSON:API, müşteri ve misafir token’ı. Tema motoru (Twig)Yeni tema yapısı, tsoft-cli, şablonlar ve global değişkenler. Eski tema (Smarty)Blok kodları, $P ürün alanları, menü ağacı, sık hatalar. LLM’ler içinllms.txt, tam metin ve her sayfanın Markdown hâli.

    #Hangi yolu seçmeliyim?

    İhtiyaç Önerilen yol Neden
    Tek mağazanın ERP, stok, sipariş entegrasyonu REST1 Web servis kullanıcısıyla çalışır, en geniş modül kapsamı.
    Birden çok mağazaya kurulacak uygulama Uygulama platformu OAuth ve webhook; REST1 kullanıcı/parola modeli kapanacak.
    REST1’de karşılığı olmayan panel işi Admin API v3 Panelin kendi uçları. Sürüm garantisi yok.
    Mobil uygulama, headless vitrin Storefront API Müşteri ve misafir oturumu, sepet, ödeme.
    Vitrin görünümü Twig veya Smarty Temanın sürümüne göre.

    Üç API, üç ayrı adlandırma: REST1 CustomerCode (PascalCase, form gövdesi), panel API’si customerId (camelCase, JSON), Storefront attributes.name (JSON:API). Hiçbiri diğerinin token’ını kabul etmez. Ayrıntı: Hangi yüzey?
